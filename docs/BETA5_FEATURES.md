# Beta 5 기능 변경 요약

이 문서는 `v0.6.0-beta.1`부터 `v0.6.0-beta.5`까지 원본 프로젝트에 제안하는 기능 변경의 범위를 정리합니다. 독립 배포용 브랜딩, 릴리즈 정책, 프로젝트 정체성 문서는 포함하지 않습니다.

## 가사 싱크와 자동 정렬

- 파형 기반 수동 싱크에 원문·발음·번역 3줄 표시, 보컬 시작점과 간주 마커, 전체 가사 보기 오버레이를 추가했습니다.
- CTC 강제 정렬과 대기열을 도입해 한국어·영어·혼합/랩 가사의 줄 시작 시각을 자동으로 제안합니다.
- 정렬 실패를 줄이기 위해 보컬 스템 우선 입력, 괄호 코러스 보존, 앵커 기반 구간 정렬, 길이 검증, 중복·역순 방지, 재시도와 취소 처리를 포함합니다.
- 잔향이 큰 보컬의 정렬 품질을 위한 선택적 디리버브 경로를 제공합니다. 자세한 준비 절차는 [DEREVERB.md](DEREVERB.md)를 참고하세요.

## 곡 추가와 라이브러리

- 유튜브와 가사 사이트 통합 검색, 공식 음원 우선 추천, 제목·아티스트 추정을 추가했습니다.
- 라이브러리는 장르와 카테고리를 분리해 관리하며, 기존 데이터의 분류값을 일관된 기준으로 재매핑합니다. 기준은 [GENRE_CATEGORY_STANDARD.md](GENRE_CATEGORY_STANDARD.md)에 있습니다.
- 분리·정렬 작업 대기열은 앱을 다시 시작해도 복원되고, 실패한 유튜브 작업은 재시도합니다.

## 분리와 오디오 엔진

- 커스텀 분리 모델 카탈로그와 안전한 추가 흐름을 제공합니다. 지원 형식과 사용법은 [CUSTOM_MODELS.md](CUSTOM_MODELS.md)에 정리했습니다.
- 선택 설치형 TensorRT GPU 가속 팩과 설치 진단을 추가했습니다. 성능 특성과 구성은 [GPU_ACCELERATION.md](GPU_ACCELERATION.md)를 참고하세요.
- 실시간 출력 장치 전환, 모니터/MR 이중 출력, 트랙 믹서, 메트로놈, 버스별 지연 보정과 출력 소프트 리미터를 추가했습니다.

## 검증 범위

- 프런트엔드 단위 테스트는 정렬 모델·대기열·LRC 파서·동기화 데이터·분류 체계를 다룹니다.
- Rust 변경은 기존 Tauri 명령과 오디오·정렬 모듈 경계를 유지하도록 구성했습니다.
